# ??? Athlete Injury Risk Prediction App

This project predicts the injury risk level (**Low**, **Medium**, **High**) of an athlete based on training workload, sleep, fitness, and injury history using machine learning. It includes a web-based interface built with Streamlit and a trained SVM model with scaling using `StandardScaler`.

---

## ?? Features Used:
- Age  
- Matches Played  
- Training Hours per Week  
- Past Injuries  
- Sleep Hours per Night  
- Fitness Test Score
